#  FastXP

Never wait for experience orbs again! **FastXP** removes the annoying vanilla cooldown when collecting XP. Experience orbs near players are instantly absorbed and credited.

##  Features
* ** Instant Pickup:** Eliminates the XP orb collection delay—perfect for high-yield Gold, Enderman, and Guardian farms.
* ** Full Mending Support:** Repaired gear comes first! Equipped items with Mending are automatically restored before remaining XP hits your level bar.
* ** Per-Player Toggle:** Players can freely toggle FastXP on or off for themselves at any time.
* ** Persistent Storage:** Player preferences are saved directly to player data and persist across server restarts.
* ** Lightweight:** Highly optimized for Paper servers with zero background tasks or performance overhead.

## ⚙️ Commands & Permissions
| Command | Description | Permission | Default |
| :--- | :--- | :--- | :--- |
| `/fastxp` | Toggles FastXP on or off | `fastxp.use` | Everyone |
